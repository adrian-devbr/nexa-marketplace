## 🚀 Projeto em destaque: NEXA

**[NEXA — Marketplace](https://github.com/adrian-devbr/nexa-marketplace)** conecta
compradores e vendedores em uma experiência com anúncios, conversas, pedidos,
avaliações e notificações.

O projeto foi desenvolvido para praticar a construção de uma aplicação
full-stack, desde a interface até a validação das regras no servidor.

**Tecnologias usadas no NEXA**

`JavaScript` · `Node.js` · `Express` · `PostgreSQL` · `HTML` · `CSS`

**O que estou construindo**

- Cadastro, login e sessão protegida.
- Anúncios moderados antes da publicação.
- Conversas ligadas aos anúncios, com bloqueio e mensagens não lidas.
- Pedidos com preços calculados no backend e fluxo de status.
- Avaliações verificadas após a conclusão dos pedidos.
- Notificações e painel administrativo.
- Estrutura de integração com checkout de teste do Mercado Pago.

> O NEXA está em desenvolvimento. O checkout requer credenciais de teste; o
> projeto ainda não está preparado para processar pagamentos reais.
